# site_buzzini

criar um site para assessoria de corrida, a naveção deve ser full page, onde cada bloco vai contar algo diferente, home vai ser um video de fundo que mostra um pouco de ocmo é assessoria, logo após terá um bloco das histórias dos alunos, seguindo o próximo bloco vamos inserir quem está por trás de fazer os treinos acontecerem, o próximo bloco uma tabela de preços, mostrando 3 planos e 3 categorias diferentes, onde serão as cidadades atendidas, seguido no próximo bloco um FAQ e por fim o rodapé
